# Node Studio

Site institucional da Node Studio.

## Estrutura

- `index.html` — site completo (CSS, JavaScript e logos incorporados).

## Publicação

Este projeto é estático e pode ser publicado em serviços como GitHub Pages, Netlify ou Vercel.

### GitHub

1. Crie um repositório no GitHub.
2. Envie o conteúdo desta pasta para a raiz do repositório.
3. Para GitHub Pages: abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch principal (`main`) e a pasta `/ (root)`, depois salve.

## Formulário de contato

O formulário usa Formspree (`https://formspree.io/f/mljbopyl`) e envia os campos diretamente pelo navegador.
O recebimento depende de o formulário estar ativo e de o endereço destinatário estar confirmado na conta Formspree.

Antes de divulgar o site, faça um envio real de teste e confirme o recebimento.

## Observações

- Não há etapa de build nem dependências para instalar.
- Abra `index.html` no navegador para visualizar localmente.
